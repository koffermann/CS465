<br><b>Architecture</b>
<br><i>Compare and contrast the types of frontend development you used in your full stack project, including Express HTML, JavaScript, and the single-page application (SPA). Why did the backend use a NoSQL MongoDB database?</i>
<br>
<br> For frontend development, Express HTML was used to essentially creat the visual aspect of travlr, JavaScript assisted in doing the heavy lifting in terms of making the site functional, and our SPA page served as our administration page where changes (like adding trips) can be done without constantly hardcoding it into Visual Code. The backend used a NoSQL MongoDB database because we needed a method of storing information about travlr's different trips and then accessing them later when we needed them. MongoDB would allow travlr to store data about trips, users, admins, etc. and then perform queries later when that data needs to be found.

<br><i>How is JSON different from Javascript and how does JSON tie together the frontend and backend development pieces? Provide instances in the full stack process when you refactored code to improve functionality and efficiencies, and name the benefits that come from reusable user interface (UI) components.</i>
<br>
<br> JSON is different from Javascript in that it is very versatile. It can be used within different types of programming languages, and can also be reused easily as an  object. During the full stack development process, code was refactored from HTML to JSON which was a noticeable improvement to the trips page, especially. Reusable UI components come with benefits like saving time for programmers and faster loading time for users.
